# Java Knowledge Test — FRC 6901

**Rules:** No IDE, no Google. Pen and paper or plain text editor. Each file has **PREDICT** and **WRITE** sections.

To get started, please *create a fork* of the repository, answer each question to the best of your abilities, and push to your fork. From there, please ping one of the leads in Discord notifying them of your completion. Feel free to ask questions as needed.

Remember, this is only a benchmark so please do NOT cheat as it only hinders our ability to grow as a team.

| File | Topics |
|---|---|
| `Q1_References.java` | Pass-by-value, object references, mutation |
| `Q2_Inheritance.java` | Polymorphism, method dispatch, overriding |
| `Q3_Scoping.java` | Static vs instance, shadowing, initialization |
| `Q4_ControlFlow.java` | Short-circuit, switch, loops, edge cases |
| `Q5_Lambdas.java` | Functional interfaces, effectively final, capture |
| `Q6_Tricky.java` | Autoboxing, interning, null, equality |

**Grading:** Compile & run to check predictions. For WRITE sections, paste your code into the file and verify it compiles + passes.
